# 🤖 AI-Driven Study Diary

Proyecto didáctico desarrollado durante el curso **Desarrollo con IA** de *El Nuevo Programador*.

Aunque la aplicación implementada es un sencillo diario de sesiones de estudio, el verdadero objetivo
del proyecto ha sido experimentar y aprender metodologías modernas de desarrollo asistido por Inteligencia
Artificial, aplicando flujos de trabajo utilizados actualmente en entornos profesionales.

---

## 📋 Descripción

La aplicación permite registrar sesiones de estudio y visualizar el progreso mediante rachas de aprendizaje.

Sin embargo, el foco principal del proyecto no ha sido la complejidad funcional, sino la aplicación práctica
de nuevas técnicas de desarrollo apoyadas por agentes de IA.

---

## 🎯 Objetivos de aprendizaje

Durante el desarrollo del proyecto se han trabajado los siguientes conceptos:

- Spec-Driven Development (SDD)
- Desarrollo asistido por Inteligencia Artificial
- Context Engineering
- AI Agents
- Subagents
- AGENTS.md
- Comandos personalizados
- MCP (Model Context Protocol)
- Planificación guiada por especificaciones
- Automatización de tareas de desarrollo
- Iteración colaborativa humano-IA

## 🧠 Conceptos aprendidos

### Spec-Driven Development (SDD)

Desarrollo basado en especificaciones previas.

Antes de implementar funcionalidades se definen requisitos claros, criterios de aceptación y comportamiento
esperado del sistema.

---

### AI Agents

Uso de agentes especializados para resolver tareas concretas durante el ciclo de desarrollo.

Ejemplos:

- Análisis de código
- Refactorización
- Generación de documentación
- Creación de pruebas
- Revisión de arquitectura

---

### Subagents

División de responsabilidades entre agentes especializados para abordar problemas complejos de forma modular.

---

### Context Engineering

Preparación y organización del contexto proporcionado a los modelos de IA para obtener respuestas más precisas y útiles.

---

### AGENTS.md

Definición formal de instrucciones, responsabilidades y comportamiento de los agentes utilizados durante el desarrollo.

---

### Custom Commands

Creación de comandos reutilizables para automatizar tareas habituales dentro del entorno de desarrollo.

---

### MCP (Model Context Protocol)

Exploración de la integración entre agentes de IA y herramientas externas mediante protocolos estandarizados.
